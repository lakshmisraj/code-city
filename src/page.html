    What this is

    Code City shows a code project as a city, so you can see its shape at a glance.

    Reading the city

    • Each building is a file. Taller means more lines of code.
    • Each district is a folder.
    • Fire on a roof means a TODO note in the code.
    • Lines between buildings show which file uses which.
    • Lit buildings are the ones the open panel is about. The rest dim.

    Good to know

    Ask, tours and explanations are written by AI, so check them against the code. Signing in to GitHub turns them on and lets you load more.
