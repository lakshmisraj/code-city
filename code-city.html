    How to read the city
    Building = one file. Height = lines of code. Width = number of functions. Districts = folders, raised one step per level. Fire on the roof = TODO / FIXME / HACK comments. Change heat = how many commits touched the file; hot files are where bugs tend to live. Hotspot = a file in the top tenth for changes; the Hotspots list ranks by commits × lines.
